# Dataset Information

The experimental workflow utilises structured enterprise financial distress prediction datasets derived from publicly available Taiwan Economic Journal financial records and related research repositories hosted through Kaggle.

## Dataset Characteristics

| Property | Value |
|---|---|
| Total observations | ~6,819 |
| Financial attributes | 96 |
| Prediction task | Binary classification |
| Bankruptcy prevalence | ~1.8% |
| Imbalance condition | Severe minority sparsity |

The dataset contains structured financial indicators associated with:

- leverage,
- liquidity,
- retained earnings,
- profitability,
- solvency,
- operational efficiency,
- and enterprise financial stability.

## Access Information

Due to licensing and redistribution considerations, the complete dataset is not directly redistributed within this repository.

Researchers may access equivalent publicly available datasets through:

- Taiwan Economic Journal research references
- Kaggle bankruptcy prediction repositories
- publicly accessible financial distress prediction datasets

## Repository Usage

The repository provides:

- preprocessing workflows,
- feature-engineering pipelines,
- imbalance-mitigation procedures,
- model-training infrastructure,
- and reproducibility-oriented experimentation logic

required to reproduce the experimental framework described in the accompanying research paper.
